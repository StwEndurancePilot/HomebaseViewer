# Third-party source and assets

The renderer modules under `src/penny`, the outpost zone data, and `assets/outpost-game` are extracted from [ahmed5939/penny-launcher](https://github.com/ahmed5939/penny-launcher), commit `bfae5210fdf4ffa408ec2bf5eb1d34e31ca7ea4f` (retrieved 2026-10-26). Penny is a GPL-3.0 fork of Aerial Launcher by Ciensprog, based on Potato Launcher. Credit belongs to those authors and contributors. This derived project retains GPL-3.0; see LICENSE.

Changes: replace the rounded packed-layout parser with a local SpriteSaveGame/capture importer; retain exact primary mesh identities and world transforms; new desktop shell and interface; add reflection handling, fidelity reporting and import/transform tests. Version 1.5 adds a session-only device-login/cloud-download service adapted from Penny's authentication and outpost sources. Penny's account database, persistent device credentials, other HTTP APIs and updater are not included.

The cloud converter reads raw actor records before Penny's layout rounding. Its class/component catalog contains asset metadata observed in local menu captures, with no account identifiers or world actor positions. The bundled native save container has an empty generic capture payload. `scripts/build/build-cloud-catalog.ts` generates both from menu saves read-only. These mappings do not establish exact geometry for every cloud archive; conversion limitations are documented in README.md.

Version 1.5.1 reads Penny's documented `accounts.json` / `enc:v1:` secret format and follows the existing STW launcher's read-only Windows import flow. Windows DPAPI unwraps Penny's key; AES-GCM authenticates each encrypted value. The source files remain untouched and the viewer creates no persistent account store.

Penny assets retain their original provenance and LICENSE files. Recovered Fortnite meshes/textures remain Epic Games assets; this project's code license does not confer new rights over those assets. Penny's build exporter uses LOD1 and compressed/quantized GLB data. Character animation and sky assets have their own licenses in their asset directories (including CC0 sources). Extraction recipes are in the pinned upstream repository under `scripts/outpost-asset-recovery`.

Primary parts are matched using GLTFLoader's association with actual source mesh names in the GLB. The older `extract_trap_models.py` display-name/part-index mapping does not describe the bundled binary. The current binary uses the blueprint assembly pipeline in `extract_blueprint_models.py`, including `seat_trap` adjustments. Version 1.0.1 reverses the documented horizontal -256 UE Y centering on audited edge-origin source meshes before applying saved transforms. The separate vertical ceiling seating and other component details remain unverified without original exports.

Three.js is MIT licensed. Electron and other dependencies retain their upstream licenses; the portable Electron folder includes Chromium/Electron notices. Keep the license/provenance files with any distributed copy and provide the corresponding GPL source for this derived viewer when distributing it.

The readable perk catalog in `src/data/perks.json` is copied from Penny Launcher's `src/features/world-inventory/weapon-perks.json` at the pinned upstream revision. It supplies descriptions and rarity labels only; saved perk order, duplicate rolls and unknown IDs are retained. Unmapped IDs are shown explicitly and missing perk records are never inferred.

Version 1.5.6 adds original Healing Pad, Flame Grill and Anti-Air meshes/textures extracted read-only from the local Fortnite 42.40 installation with [CUE4Parse](https://github.com/FabianFG/CUE4Parse) / CUE4Parse-Conversion 1.2.2.202610 (Apache-2.0; development tool only). These remain Epic Games assets. Native mesh pivots are retained. Anti-Air component transforms come from its actual blueprint construction hierarchy; live aim and animated materials are not represented. `assets/outpost-game/recovered-traps/provenance.json` records source hashes and transformations, and the portable notices folder retains that provenance.

Version 1.2 uses official Material Web components and Material Color Utilities (Apache-2.0), Roboto Variable (SIL Open Font License 1.1), Phosphor Icons (MIT), and Lit packages (BSD-3-Clause). All fonts, icons, components and color calculations are bundled locally; there is no runtime font CDN or theme service. Their license texts are retained in notices/. Material components supply controls, and the custom editor shell uses Material 3 semantic tokens. The blue theme is generated from #3678D7.

Version 1.5.8 bundles 25 trap icons and the wood, stone and metal inventory icons, copied unchanged from the pinned Penny revision. The artwork remains Epic Games property. `assets/inventory/provenance.json` records each upstream path and SHA-256. Perk rows are a custom STW-inspired presentation using Phosphor glyphs and saved perk rarity; they are not captured game UI. All artwork loads locally.

Version 1.6.0 adds `src/data/build-edits.json`, extracted read-only from the local Fortnite 42.40 edit-pattern and player-building blueprint assets using the same CUE4Parse helper. It contains 33 native masks and 296 class/mesh definitions verified against the bundled Penny meshes. `scripts/build/build-edit-catalog.py` documents family aliases, source pattern filenames and hashes. No live game files are changed.

Version 1.7 adds electron-updater (MIT) for GitHub release downloads and integrity checking, and electron-builder (MIT; development tool) for the NSIS installer. The updater license is copied into notices; runtime dependencies retain their own license files in the application archive. The H icon in assets/branding is project artwork matching the existing interface.
